# Шаблонный класс `Vector<T>` на C++

Реализация собственного динамического массива (аналога `std::vector`) с использованием шаблонов классов, перегрузкой операторов и специализацией для типа `std::string`.

## 📋 Описание проекта

В рамках работы реализован шаблонный класс `Vector<T>`, поддерживающий автоматическое управление динамической памятью (При помощи правила трёх) и базовые операции для работы с последовательностями данных.

### Реализованный функционал:
* **Управление памятью:** конструктор по умолчанию, конструктор копирования, оператор присваивания  и деструктор.
* **Методы работы с элементами:** `push_back()`, `front()`, `back()`, `at()` (с проверкой выхода за границы), `operator[]`, `clear()`, `reserve()`, `size()`, `capacity()`.
* **Перегрузка операторов (общий шаблон):**
  * `+` — поэлементное сложение векторов;
  * `-` — поэлементное вычитание векторов;
  * `*` — скалярное произведение векторов;
  * `<<` — форматированный вывод вектора в поток (`[el1, el2, ...]`);
  * `>>` — ввод элементов вектора из потока.
* **Специализация операторов для `std::string`:**
  * `+` — поэлементная конкатенация строк через пробел;
  * `-` — удаление подстроки второго вектора из соответствующей строки первого;
  * `*` — объединение всех пар элементов в единую строку формата `(str1:str2)`.
