# Домашнее задание №11 «Исключения»

## Постановка задачи

Внести изменения в домашнее задание №10. 
1. Реализовать обработку исключений. 
2. Генерировать и обрабатывать минимум три разных типа исключений, одним из которых должно быть исключение — объект класса.

## Тема программы

Программа описывает фильмы и киносеансы. Используется иерархия классов:

- `Movie` — абстрактный класс фильма;
- `SciFiMovie` — фантастический фильм;
- `HorrorMovie` — фантастический фильм ужасов;
- `MovieSession` — киносеанс, содержащий указатель на фильм.

В программе сохранены элементы домашнего задания №10: статический метод создания киносеанса и изменение полей вложенного объекта с помощью нисходящего приведения типов.

## Реализованные исключения

### 1. `std::invalid_argument`

Генерируется методом `SetHallName`, если передано пустое название зала.

```cpp
if (newHallName == nullptr || strlen(newHallName) == 0) {
    throw invalid_argument("Название зала не может быть пустым");
}
```

### 2. `std::out_of_range`

Генерируется методом `SetTicketPrice`, если цена меньше 1 или больше 5000 рублей.

```cpp
if (newPrice <= 0 || newPrice > 5000) {
    throw out_of_range("Цена билета должна быть от 1 до 5000 рублей");
}
```

### 3. `MovieNotAssignedException`

Это собственный класс исключения. Его объект генерируется, если программа пытается вывести или изменить фильм в сеансе, которому фильм не назначен.

```cpp
class MovieNotAssignedException : public std::exception {
public:
    const char* what() const noexcept override;
};
```

Все исключения перехватываются в `main` с помощью блоков `try-catch`, поэтому программа сообщает об ошибках и продолжает работу.

## Файлы проекта

- `movie.h` — объявления классов;
- `movie.cpp` — реализация методов;
- `main.cpp` — создание объектов и проверка трёх исключений.
