# ДЗ №12 «Перегрузка операторов»

Программа демонстрирует класс `Complex`. В нём два закрытых поля типа
`double`: действительная и мнимая части числа. Класс содержит конструктор
по умолчанию, конструктор с параметрами, конструктор копирования,
деструктор и метод `Show()`.

## Как работают операции

- `+`, `-`, `*`, `/` возвращают новое число. При делении на ноль
  программа выводит сообщение об ошибке.
- `=` копирует обе части числа, а `+=` прибавляет обе части к текущему числу.
- `++` прибавляет 1 к действительной части, `--` вычитает 1. Префиксная
  форма возвращает изменённое число, постфиксная — копию до изменения.
- `>`, `<`, `==`, `!=` сравнивают модули. Например, у `2+1*i`
  и `1-2*i` модули равны, поэтому `==` возвращает `true`.
- Дружественная функция `>>` читает два числа через пробел, а
  `<<` выводит их в виде `a+b*i` или `a-b*i` в зависимости от знака.

В `Complex.h` объявлен класс, в `Complex.cpp` описаны методы и операторы,
а в `main.cpp` показано их использование.

## Проверка

Введите два любых числа, например `3 4`. Второе число уже задано в программе как `1-2*i`.
Сумма будет `4+2*i`, разность — `2+6*i`, произведение — `11-2*i`,
а частное — `-1+2*i`. При вводе `2 1` можно проверить равенство по модулю.
